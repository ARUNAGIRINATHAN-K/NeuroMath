# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

NeuroMath is an educational and numerical reference repository. However, if you discover a security issue (e.g., in dependency specifications, serialization safety, or data handling), please report it responsibly:

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email details of the vulnerability to the maintainer at `arunagirinathan.k@example.com` or initiate a Private Security Advisory via GitHub's Security tab.
3. You will receive an acknowledgment within 48 hours with next steps and a mitigation timeline.
